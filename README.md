# شركة وفقًا — WIFQA

وفقًا يقارن عروض نفس نسخة المنتج عبر المتاجر حسب أولوية العميل والتكلفة عند الوصول والشحن والإرجاع والأدلة. البحث عن النادر قدرة إضافية؛ البطارية حالة اختبار.

## النموذج الحالي
واجهة عربية RTL ومحرك مقارنة على بيانات تجريبية محلية من `data/products.json`. يعيد `/api/search` بيانات demo موسومة عند غياب مزود حي؛ لا يتطلب التشغيل مزودًا خارجيًا أو مدفوعات.

يختار المستخدم إحدى المناطق السعودية الثلاث عشرة. لا يدخل العرض ترتيب الأرخص أو الأسرع إذا كان الشحن إلى المنطقة غير معروف. لكل سعر وشحن وموعد وصول حالة ومصدر ووقت تحقق، وتظهر شارة «بيانات تجريبية» وتاريخ تحديث الملف. الحالات تشمل شحنًا مجهولًا ونسخة مختلفة وخصمًا غير مثبت وموعدًا يختلف حسب المنطقة ومتجرًا لا يشحن إلى منطقة معينة.

تاريخ الملف وأوقات أدلته ثابتة، ولا تُستبدل بوقت الطلب. الأدلة الأقدم من 24 ساعة تصبح غير معروفة ويخرج العرض من الترتيب؛ عند تحديث العينة حدّث `updatedAt` وأوقات حقولها صراحة. حالة «مؤكد» في demo تخص بيانات التجربة فقط، وليست تحققًا من متجر.

## التشغيل المحلي
يتطلب Node 24. لا تثبيت مكتبات مطلوب.

```sh
npm test
npm run build
npm start
```

بعد البناء افتح http://127.0.0.1:4173. الواجهة تستخدم عينة AirPods التجريبية؛ تبقى بيانات WF-DEMO القديمة لاختبارات المحرك فقط. خيارات السيناريو تختبر النفاد والتعارض، وأولوية العميل تغير الترتيب.

لإعادة فحص المتصفح المحلي بعد تشغيل الخادم، مع وجود Chromium:

```sh
node scripts/quality/demo-browser-check.mjs
```

تُحفظ نتائج المناطق وRTL والجوال ولقطات الشاشة في `evidence/regional-demo/`. البناء يزيل صياغة TypeScript ولا يقوم بفحص الأنواع الثابتة؛ لم تُجر اتصالات حية أو معاملات شراء.

راجع [قرار التقنية والتحقق](docs/TECHNICAL_DECISION_D016.md)، [المهام](docs/TASKS.md)، [تقرير الجودة](docs/QUALITY_CODE_REVIEW_2026-10-11.md)، و[خطة المرحلة الثانية](docs/PHASE_2_ENTRY_PLAN.md). الحقيبة الأصلية في Drive؛ نسخ الوثائق المسجلة داخل foundation لقطة مراجعة وليست مزامنة تلقائية.

التغييرات في مسودة PR 1؛ لا دمج أو نشر عام قبل اعتماد المالك. لا دفع أو API مدفوع أو حسابات متاجر مدمجة.
