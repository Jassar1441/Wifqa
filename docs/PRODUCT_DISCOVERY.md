# استكشاف المنتج الأول — مسودة غير معتمدة

الحالة: **مقترح يحتاج مراجعة صاحب المشروع**. لا يمثل متطلبات نهائية ولا تطبيقًا جاهزًا.

## المشكلة المراد حلها
يصعب على المتسوق التحقق من المطابقة الفعلية للمنتج، والتفريق بين الإعلانات والمواصفات القابلة للإثبات، ومقارنة التكلفة الإجمالية والمخاطر قبل الشراء.

## فرضية المنتج
وكيل تسوق عربي يساعد على: توضيح الحاجة، جمع خيارات من مصادر مشروعة، التحقق من المواصفات والدليل، بيان مدى المطابقة والاختلاف، ثم عرض مقارنة واضحة مع درجة اليقين، من دون تنفيذ شراء تلقائي.

## نطاق إصدار تجريبي مقترح (لا يبدأ تنفيذه قبل مراجعة الحقيبة التأسيسية)
1. إدخال وصف الحاجة والمعايير الملزمة والميزانية والبلد.
2. إدراج خيارات وروابط مصادر موثقة؛ إن تعذر الجلب المباشر، إدخال الخيارات يدويًا لنسخة أولية.
3. سجل لكل منتج: الاسم، الطراز، البائع، السعر، العملة، الشحن، الضمان، رابط المصدر وتاريخ التحقق، معلومات غير مؤكدة.
4. مقارنة شرطية: مطابق / غير مطابق / لم يتم التحقق؛ مع أسباب موجزة ومراجع.
5. عرض التكلفة الإجمالية *عندما تكون جميع البيانات متاحة*، وإلا إظهار المفقود صراحة.
6. تلخيص واضح للمفاضلات؛ المستخدم يختار ويشتري بنفسه خارج النسخة التجريبية.

## مثال اختبار واقعي
بطارية طائرة صغيرة: الفولت، السعة mAh، أبعاد البطارية، نوع القابس، ترتيب الأقطاب، اتجاه الأسلاك، توافق الشاحن؛ **لا تكفي مطابقة السعة أو الشكل وحدهما**. لا تُستنتج القطبية من لون الأسلاك فقط.

## ما ليس ضمن الإصدار الأول
- شراء أو دفع أو إدارة بطاقات.
- ادعاء توفر/سعر حالي من دون مصدر ووقت تحقق.
- كشط مواقع يخالف الشروط أو وصول غير مصرح به.
- اشتراكات مدفوعة أو مفاتيح API مفترضة.
- حسابات متعددة أو ذكاء اصطناعي مستقل يعمل دون رقابة.

## معايير قبول أولية
- بيانات كل مقارنة موصولة بمصدر أو معنونة بأنها تقدير/غير معروفة.
- الشروط الملزمة المستحيلة أو غير المتحققة تُعرض بوضوح.
- التحذير عند غياب معلومات السلامة ذات الأثر الحاسم مثل قطبية البطارية.
- تجربة عربية مناسبة لشاشة الجوال.
- عدم تخزين بيانات حساسة أو أسرار في المستودع.

## قرارات لازمة قبل البرمجة
- استرجاع وفحص الحقيبة التأسيسية الأصلية (15 ملفًا)؛ لا يوجد تحقق منها هنا.
- تثبيت طبيعة المنتج الأول وترتيب أولوياته.
- تحديد مصادر بيانات المنتجات المسموح بها والتراخيص والبلدان المدعومة.
- اعتماد واجهة أولية ومقاييس نجاح واختبارات.
