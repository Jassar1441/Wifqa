# تسليم تجهيز مصدر بيانات حقيقي — دون افتراض اتصال حي

المرجع المحلي: docs/EXTERNAL_DATA_CONTRACT.md وsrc/ingest.ts. الحالة: عقد تحضير وتوزيع عمل؛ لا مصدر حي مربوط أو صلاحية مثبتة بمجرد هذا الملف.

## ما يمكن تحضيره الآن قبل اختيار المنتج

سجل المصدر وخريطة تحويل الحقول، وسياسة النقص والتعارض، وعينات اصطناعية موسومة، واختبارات تعطل وفشل صلاحية المصدر، وسجل أدلة، ونموذج تقرير مقارنة فارغ. كلها أعمال محلية قابلة للتنفيذ دون بيانات متجر أو ميزانية أو انتظار قرار منتج.

## سجل المصدر وصلاحية الاستخدام

| الحقل | ما يسجل | حالة البدء |
|---|---|---|
| source_id واسم المزود وطريقة الوصول | معرف موصل ومصدر API/ملف/رابط يدوي | غير محدد إلى تقييم المصدر |
| permission_status | unknown/pending/allowed/denied/revoked |unknown |
| permission_evidence | رابط الشروط أو التفويض ونطاق الاستخدام وتاريخ المراجعة | غير موجود؛ لا يحول unknown إلى allowed |
| allowed_operations | قراءة، تخزين، إعادة عرض، نسب المصدر، قيود المناطق |unknown لكل عملية حتى الدليل |
| limits_and_cost | حدود طلبات وتحديث وتخزين وتكلفة |unknown؛ لا يفترض أنها مجانية |
| covered_fields | الحقول الموفرة والناقصة وتواتر التحديث | قائمة فارغة إلى الفحص |
| owner_and_review | مسؤول المصدر وتاريخ مراجعة أو تغير شروط | مسؤول البحث؛ يملأ عند التقييم |

permission_status سجل تخطيط/موصل مقترح، وليس حقلًا منفذًا حاليًا في Offer. لا يُضاف إلى النموذج وكأنه موجود. denied أو revoked يمنع القراءة/الجلب؛ unknown أو pending يمنع تفعيل الموصل الحقيقي، مع استمرار الاختبارات المحلية. لا التفاف على الحماية ولا دخول لحسابات متجر شخصية.

## حقول العرض وخريطة النقص

| المجموعة | حقول العقد الحالي | عند غياب الدليل |
|---|---|---|
| الهوية |id,seller,title,identity(model,size,concentration,condition,quantity) | لا تختلق موديلًا؛ اختلاف النسخة يفصل، والمعرف لكل عرض وبائع |
| الشروط |specifications وmustHave في الطلب | الناقص تحت شرط إلزامي بحاجة للتحقق؛ المخالف يستبعد |
| المبالغ |currency,price,shippingCost,taxIncluded,tax,fees,coupon |null للمجهول حيث يدعم العقد؛ unknown ليس صفرًا، ولا تحول نصًا إلى رقم ضمنيًا |
| التوفر |availability:in_stock/out_of_stock/unknown |unknown؛ اسم الصفحة لا يثبت مخزونًا |
| الوجهة |shipping.available,country,city |available=null عند الغموض؛ الوجهة من الطلب، لا تستنتج وصول أبها من وجود شحن عام للسعودية |
| الموعد |delivery.minDays,maxDays,status |null وunknown؛ تقدير منفصل عن ضمان، والمدة المعكوسة غير صالحة |
| الإرجاع |returns.days,cost,notes,status | قيم null وحالة unknown؛ لا تكتب مجانيًا أو عدد أيام بلا دليل |
| البائع |sellerEvidence.verifiedIdentity,status |false وunknown مع الدليل الناقص، لا ضمان جودة من هوية فقط |
| الأدلة |evidence لكل claim مؤثر:status,source,checkedAt |unknown/source فارغ/تاريخ فارغ في الحالة الناقصة؛ لا timestamp جديد لادعاء لم يتحقق |
| نوع البيانات والرابط |dataKind,url |synthetic للعينة المحلية؛ live لا يصنع تحققًا، وHTTPS فحص صيغة فقط |

القيم null والحقول الفارغة ليست بدائل لكل الحقول: يلزم الالتزام بتوقيع العقد. إذا غاب حقل لا يقبل null مثل country أو currency، يرد الموصل مشكلة واضحة ولا يخترع قيمة لتمرير السجل. يمكن تجهيز دالة تطبيع صريحة لاحقًا، مع مصدر لكل تحويل وحدة أو عملة، لكنها غير مفترضة منفذة الآن.

## مسار القبول المقترح

1. **قبول العقد المحلي:** موصل اختبار يولد rawOffers وrawRequest ويمر عبر compareExternal؛ لا استدعاء compare الداخلي مباشرة من مصدر خارجي.
2. **قبول النقص والفساد:** نص بدل رقم، string بدل boolean، حقل مفقود، Infinity/NaN، معرف مكرر، طلب بلا model، شروط min>max؛ يعزل السجل مع السبب ويظل العرض الآخر صالحًا للتقييم.
3. **قبول قواعد المعنى:** المصدر يؤكد بنية سليمة لكنها تخالف نسخة/شرط/توصيل/مخزون؛ المحرك يستبعد أو يوسم بحاجة للتحقق بدل قبولها لمجرد صحة JSON.
4. **قبول إذن المصدر G1:** أدلة صلاحية كل عملية وحدودها وتكلفتها؛ لا يبدأ جلب حقيقي قبل ذلك. لا يتوقف تجهيز 1–3 عليه.
5. **قبول العينة الحقيقية:** بعد اختيار المنتج والمصدر، فحص مستقل للرابط والنسخة والتوفر والسعر ومكونات الإجمالي وموعد الوجهة والإرجاع والبائع. يربط المصدر والتاريخ بكل معلومة ولا يعاد وسم fixture بوصفها حية.
6. **قبول التقرير:** خلاصة قصيرة حسب أولوية العميل، مع تفاصيل أدلتها ومفاضلاتها، والنتيجة الخالية صريحة. يبقى fulfillmentStatus=not_verified ما لم تنفذ مرحلة تحقق مستقلة ويُعتمد تغيير المؤشر بأدلة واختبارات؛ لا تعديل مسبق إلى verified.

## التوزيع والتسليم

البحث يملك سجل الصلاحية والأدلة؛ التقنية تملك خرائط الحقول والموصل المحلي؛ الجودة تختبر حدود المدخلات والمعنى والتقرير؛ التخطيط يربط العمل بمعايير القبول؛ المنسق يجمع الأدلة ويرفع النسخ المصرح بها. حالة المنتج الواقعية والميزانية والنشر يرجع فيها للمالك عند الحاجة. لا يعمل مساعدان على الملف نفسه بالتزامن.

التسليم: اسم الموصل، ونسخة العقد، وخريطة الحقول، وحالات المفقود، ونتائج الاختبار، وحدود الصلاحية، وسجل ما لم يتحقق. التحضير المحلي لا يسمى تكاملًا حيًا أو تحقيق شراء.
