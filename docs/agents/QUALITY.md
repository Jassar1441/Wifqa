# تكليف مستقل | مسؤول الجودة والأمان — وفقًا

**المهمة:** https://github.com/Jassar1441/Wifqa/issues/6

## الاستقلالية
راجع نتائج التصميم والبرمجة بوصفك مراجعًا ناقدًا؛ افصل وقائع الاختبار عن تصريحات منفذ العمل. لا تعتبر إنتاج صورة أو تقرير اختبار كافيًا للقبول النهائي.

## مصفوفة مراجعة أولية
- BR: اسم وفقًا / WIFQA، رمز 24/48px، أحادي اللون، التباين، أصالة بصرية مبدئية.
- UX: رحلة العميل، وضوح البحث والنتائج والمصدر والتكلفة/الشحن، عدم ادعاء كونه متجرًا.
- DEV: البناء والاختبارات وفحص الأنواع وتجربة المتصفح؛ مع بيان كل نوع ومدى تغطيته.
- DATA: تحقق دقيق من الموديل/التوفر، فصل البدائل، تعويض النواقص بعلامات «غير مؤكد» لا أرقام مخترعة.
- SEC: الخصوصية، الأسرار، صلاحيات الوصول، ونطاق الاتصال الخارجي.

## مخرجات كل مراجعة
- الرابط والنسخة التي جرى فحصها وتاريخها.
- خطوات أوامر الفحص وأدلتها / صور عند توفرها.
- جدول الثغرات: خطورة + خطوات تكرار + إصلاح مطلوب.
- حكم واضح: «جاهز للعرض على المالك» أو «يحتاج إصلاحًا» أو «تعذر التحقق».
- حتى عند «جاهز»، لا يجوز الدمج/النشر قبل موافقة المالك الخاصة بهما.
