# وفقًا — قائمة قبول الهوية والواجهات (مسودة)

الحالة: وثيقة مراجعة فقط؛ لا اعتماد ولا نشر.

## الشعار
- [ ] إحضار الصورة الأصلية للشعار المفضّل قبل ادعاء مطابقة المرجع.
- [ ] تقديم ثلاثة اتجاهات مرئية مختلفة فعلًا.
- [ ] اختبار وضوح الأيقونة عند 24 و48 بكسل وبالأبيض والأسود.
- [ ] فحص سلامة كتابة «وفقًا» دون الاعتماد على الترجمة الآلية.
- [ ] فحص أولي لتشابه العلامات قبل اعتماد نهائي.

## واجهة الجوال
- [ ] دعم اتجاه RTL مع بقاء الأسعار والأكواد والروابط مقروءة.
- [ ] حقول اسم المنتج والموديل والمواصفات والميزانية ووجهة الشحن.
- [ ] إظهار السعر والشحن والإجمالي مع تمييز البيانات غير المتاحة.
- [ ] فصل التطابق التام عن البدائل وعدم عرض غير المتوفر على أنه متوفر.
- [ ] إظهار مصدر العرض ووقت آخر تحقق.
- [ ] زر «اذهب إلى المتجر» بدل الإيحاء بأن وفقًا تتم الشراء.
- [ ] حالات التحميل والفراغ والخطأ وعدم اليقين.
- [ ] اختبار التباين وسهولة اللمس على الهاتف.

## أدلة القبول
لكل بند: رابط لقطة شاشة أو اختبار، تاريخ الفحص، واسم المراجع. لا يُؤشّر بند مكتمل دون دليل. تُعرض النتائج على صاحب المشروع قبل اعتماد الهوية.
