## قيود التطوير

- لا دمج إلى `main`، ولا نشر، ولا مشتريات، ولا خدمات أو API مدفوعة، ولا تشغيل CI/GitHub Actions أو أي شيء قد يستهلك رصيدًا دون موافقة منفصلة.
- لا تعتبر بيانات النموذج الاصطناعية أسعارًا حقيقية أو عروضًا قابلة للشراء.
- مراجعة الكود عبر GitHub لا تعني تشغيل الاختبارات. يجب تسجيل ما لم يُنفذ بوضوح.
- الهدف المعياري: منتج فعلي يساعد العميل على الحصول على منتج مطابق وإيصاله، وليس مجرد نتائج مقارنة شكلية.
