# P1 — عزل إثباتات العروض الحية والكوبونات غير الصالحة
25 أكتوبر 2026، الجولة الصباحية. فرع مستقل مبني على رأس PR #19، وليس main.

## تغييران
1. عزل العرض الذي يفشل دليل هوية المنتج أو المواصفة الإلزامية أو السعر أو التوفر أو الشحن، مع إبقاء العروض السليمة من رد المصدر نفسه. يستمر رفض أي سجل `synthetic` في رد `live` كاملًا. يمر الإدخال البنيوي عبر `compareExternal`، ولا يرفع العرض غير المؤكد إلى قائمة المطابق.
2. عند تلف بنية الكوبون أو إثباته، يُلغى **الخصم فقط** مع إبقاء المنتج للمقارنة إذا كانت بياناته الأساسية صحيحة. تفصل رسالة التحذير بين عدد العروض المعزولة وعدد الخصومات الملغاة.

## الاختبار المنفذ فعليًا
في نسخة اختبار محلية معزولة من الملفات الجديدة، باستخدام `src/ingest.ts` و`src/live-proof.ts` و`src/evidence-time.ts` المسترجعة من أدلة الجولات السابقة، و**بديل اختبار بسيط لدالة compare** بدل محرك المقارنة الفعلي:

```sh
node --version
# v22.16.0
node --experimental-strip-types --test tests/live-offer-gate.test.ts tests/search-gate-integration.test.ts
# 14 tests, 14 passed, 0 failed
node --experimental-strip-types --check src/live-offer-gate.ts
node --experimental-strip-types --check src/live-issues.ts
node --experimental-strip-types --check src/search-client.ts
node --experimental-strip-types --check tests/live-offer-gate.test.ts
node --experimental-strip-types --check tests/search-gate-integration.test.ts
# all syntax checks succeeded
```

الاختبارات شملت: سلامة سجل حي، فساد دليل الهوية أو المواصفة أو السعر أو الشحن، بقاء عرض سليم، فساد بنية الكوبون أو إثباته، السعر النصي، المعرف المكرر، رفض خلط المحاكاة، وربط مسار `searchAndCompare` بالبوابة الجديدة. بيانات الاختبار `merchant.example` اصطناعية وغير معروضة كمصدر حقيقي.

## حدود الإثبات
- لم ينجح استنساخ المستودع الخاص محليًا: `Could not resolve host: github.com`. استُخدم موصل GitHub للقراءة والكتابة وإعادة جلب الملفات.
- لم تُنفذ اختبارات المستودع كاملة، ولا البناء، ولا فحص أنواع TypeScript، ولا تجربة متصفح/جوال، ولا جلب متجر حي. Node المحلي 22.16، بينما `package.json` يتطلب Node 24 أو أحدث.
- الاختبارات المحلية **ليست** إثباتًا لتشغيل محرك المقارنة الكامل؛ الاختبارات الجديدة المضافة للمستودع تنتظر تشغيل CI أو بيئة Node 24 على المستودع الحقيقي.
- هذا فرع تغييرات متراكب فوق PR #19؛ لا يجوز دمجه منفردًا إلى main أو نشره.

## إحالة الجودة #6
يرجى تشغيل `npm test` و`npm run build` على Node 24، والتحقق من مرور الاختبارات الجديدة مع محرك المقارنة الحقيقي، ثم اختبار عزل عرض غير صالح وسط عروض صحيحة، وعدم تطبيق كوبون معطوب، والتمييز بين التحذيرين في الواجهة، وعدم عرض المحاكاة كبيانات حية. إصدار حكم QA مستقل قبل أي طلب اعتماد من المالك. لا دمج أو نشر أو صلاحيات أو إنفاق.
