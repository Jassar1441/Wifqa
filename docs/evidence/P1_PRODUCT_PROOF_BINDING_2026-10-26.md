# P1 — ربط دليل المنتج والمواصفات والسعر والتوفر بنفس النسخة | 26 أكتوبر 2026 صباحًا

## نطاق العمل
- المهمة 1: `src/live-proof.ts` يرفض دليل الهوية والمواصفات الإلزامية إذا جاء من صفحة منتج مختلفة داخل المتجر نفسه أو من معرّف `variant`/`sku` مختلف.
- المهمة 2: `src/live-offer-gate.ts` يعزل العرض الذي يستند سعره أو توفره إلى صفحة منتج/نسخة مختلفة، مع إبقاء العروض السليمة. دليل الشحن يبقى مقيدًا بأصل المتجر، لأن صفحة سياسة الشحن قد تكون مستقلة عن صفحة المنتج.
- اختبارات انحدار: `tests/p1-product-proof-binding.test.ts` (5 حالات تشمل اختلاف المسار والنسخة والسعر والتوفر وقبول معاملات تتبع لا تغيّر النسخة).

## الاختبار المنفذ فعليًا
بيئة محلية معزولة مستخرجة من حزمة أدلة الجولة السابقة `wifqa_2026_10_25_am_evidence.zip`، مع تطبيق التعديلين واختبارات الانحدار؛ ليست استنساخًا كاملًا للمستودع.
- البيئة: Node.js v22.16.0 (المشروع يشترط Node >=24).
- قبل التصحيح: `node --experimental-strip-types --test tests/p1-product-proof-binding.test.ts` → 1 ناجح، 4 فاشلة، أظهرت قبول دليل من منتج/نسخة أخرى.
- بعد التصحيح: `node --experimental-strip-types --test tests/*.test.ts` → **19 ناجحة، 0 فشل** (14 اختبارًا معزولًا موجودًا + 5 انحدار).
- فحص الصياغة: `node --experimental-strip-types --check src/live-proof.ts` و`node --experimental-strip-types --check src/live-offer-gate.ts` → ناجحان.

## ما لم يُتحقق منه
لم تُشغّل اختبارات المستودع كاملة `npm test` أو `npm run build` أو TypeScript typecheck أو تجربة متصفح/جوال أو مصدر متجر حي. الاختبارات المعزولة لا تثبت تكامل التطبيق كاملًا، ووجود رابط من أصل المتجر ومسار مطابق لا يثبت استقلاليًا صحة محتوى الصفحة. يلزم اختبار حقيقي مع مصدر مصرح، وفحص الحالات التي تعتمد صفحات مصادر بديلة.
