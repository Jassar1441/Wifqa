## حل النسخ القابل للتنفيذ
أضيف `scripts/backup_wifqa.py`. يتطلب Python 3 وGit وبيئة **مصرحًا لها مسبقًا** بقراءة المستودع الخاص.
لا تضع رمز وصول في الأمر أو عنوان المستودع أو المحادثة.

```sh
python scripts/backup_wifqa.py --output Wifqa-backup-2026-10-13
```

الأداة:
1. تنشئ mirror في مجلد جديد؛ ترفض إعادة استخدام مجلد موجود.
2. تفحص git fsck --full --strict، وتوقف الادعاء بالاكتمال إذا اكتشفت LFS.
3. تنشئ Wifqa-all.bundle وتفحص bundle verify.
4. تستعيد الحزمة إلى مستودع مستقل وتطابق refs وجميع كائنات التاريخ القابلة للوصول.
5. تنتج SHA-256 وbackup-verification.json؛ تبقى driveUploaded=false.
