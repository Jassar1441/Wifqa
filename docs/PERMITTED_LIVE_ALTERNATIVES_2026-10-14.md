# فحص بدائل المصدر الحي — 14 أكتوبر 2026

## التقدم الجديد
فُحصت الوثائق الرسمية الحالية لمصدر Shopify Global Catalog، وجرير وإكسترا ونون. لم يُرسل طلب منتج لأي متجر أو API، ولم يُنشأ حساب أو تُقبل اتفاقية أو تُنشر هوية أو مفتاح.

## المرشح الأقوى: Shopify Global Catalog UCP MCP
- الوثيقة الرسمية: https://shopify.dev/docs/agents/catalog
- مرجع API: https://shopify.dev/docs/agents/catalog/global-catalog
- endpoint: https://catalog.shopify.com/api/ucp/mcp
- الوثائق تصفه صراحةً بأنه مناسب للمقارنة بين المتاجر. يدعم search_catalog بالنص وفلتر ships_to.country=SA وavailable=true، وإرجاع الأسعار بالوحدات الصغرى والعملات والتوفر والبائع.
- لا يحتاج API key بحسب جدول Catalog interfaces. يحتاج agent profile؛ الأمثلة الرسمية تستعمل الملف المستضاف من Shopify: https://shopify.dev/ucp/agent-profiles/examples/2026-08-25/valid-with-capabilities.json
- لذلك لا ينبغي الادعاء أن نشر نطاق أو مفتاح WIFQA شرط لازم لكل تجربة Catalog. الملف المستضاف مرجع أمثلة وليس هوية WIFQA الإنتاجية، ويعلن قدرات شراء/دفع أوسع من المطلوب؛ لا نستخدمه للإنتاج.
- القيود الرسمية: لا تخزين نتائج البحث، ولا تحميل صور المنتجات للخادم لإعادة استعمالها؛ الصور تعرض لحظيًا مع منتج التاجر؛ حدود معدلات الطلبات قائمة. الحقول inferred قد تكون مستنتجة، ولا تثبت مطابقة AirPods4 دون ANC.
- لم تثبت تغطية AirPods4 بمتاجر السعودية أو الشحن لأبها أو أسعار SAR فعليًا، لأن اختبار API لم يُنفذ.
- التكلفة: وصول keyless موثق، لكن لا يوجد في الصفحات المفحوصة ضمان تعاقدي ببقاء التكلفة صفرًا. API Terms تتيح تغيير الخدمة وفرض رسوم لاحقًا؛ لا موافقة على ذلك.

## العائق القانوني المحدد
الشروط: https://www.shopify.com/legal/api-terms (آخر تحديث ظاهر 7 أكتوبر 2026).
المقدمة تقول إن الوصول أو الاستخدام قبول لاتفاقية ملزمة. تعريف Shopify APIs يشمل MCP servers. توجد قواعد وصول وأذونات وقيود على جمع البيانات وبناء فهرس منتجات؛ وفي المقابل وثائق Global Catalog تسمح بمقارنة مشتريات بين المتاجر ومعاينات محدودة لا تخزينها.
لا نستنتج من هذا التعارض الظاهر أن جميع مقارنة Catalog ممنوعة. يصنف حق استخدام WIFQA التجاري غير محسوم حتى تحديد المسار المرخص المنطبق أو اتفاقية قائمة أو إذن واضح.
ولأن المالك منع إنشاء التزام قانوني دون موافقة، أُوقف اختبار القراءة فقط. لم تُقبل شروط نيابة عنه.

## القرار والخطوة التالية
ألف يبقى معلقًا. Global Catalog أول بديل للفحص، مع عدم نشر WIFQA أو مفتاح. جهز طلبًا تجريبيًا محدودًا بالنص AirPods 4 without active noise cancellation وSA، دون بيانات شخصية أو checkout. لا ينفذ حتى حسم الاتفاقية المطلوبة ضمن تفويض المالك؛ لا إطلاق ولا دمج.
هذه تغييرات بحث/وثائق فقط؛ لا اتصال حي ناجح ولا أسعار أو توفر حديثان مثبتان ولا تغيير برمجي.
