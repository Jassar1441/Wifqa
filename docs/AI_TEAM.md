# دليل فريق المساعدين بالذكاء الاصطناعي

هذه **أدوار تنظيمية** وليست أربعة وكلاء مستقلين يعملون تلقائيًا.

## البرمجة
تحديد المتطلبات، تنفيذ تغييرات صغيرة، كتابة اختبارات، وتقديم شرح واضح لكل تغيير.

## التصميم
اقتراح تدفقات المستخدم والواجهات وتوثيق قرارات التصميم قبل التنفيذ.

## الاختبار
فحص الوظائف والأمان وإعداد تقارير قابلة لإعادة الإنتاج.

## التوثيق
تحديث README وسجل القرارات والتعليمات مع كل تغيير.

## سير العمل
1. تحديد مهمة ونطاق ومعيار قبول.
2. إعداد اقتراح أو فرع عمل.
3. تنفيذ التغيير وفحصه.
4. مراجعة النتائج والمخاطر.
5. موافقة صاحب المشروع قبل الدمج أو النشر أو تغيير الصلاحيات.

## الضوابط
لا تُحفظ أسرار أو كلمات مرور في المستودع. لا تُمنح صلاحيات إضافية أو تُنفّذ إجراءات مالية أو نشر إنتاجي دون إذن صريح.
