# D-016 — تقنية النموذج وأدلة التنفيذ

اختير TypeScript وDOM عربي RTL وNode 24 للنموذج المحلي ضمن تكليف المالك بالتنفيذ. فصل قواعد المقارنة والبيانات والواجهة يسمح بإضافة مصدر مصرح به لاحقًا. لا تبعيات خارجية ولا تكلفة تشغيل API. Next.js اقتراح إنتاجي لاحق، وليس اعتمادًا حاليًا.

## التحقق المنجز
- 46 اختبارًا للمنطق واجتازت جميعها؛ أعاد مسؤول الجودة تشغيلها مستقلًا.
- بناء ناجح باستخدام stripTypeScriptTypes، وفحص صياغة JavaScript ناجح.
- أربعة عيوب P1 كُشفت وأُصلحت وأعيد فحصها: مدة معكوسة، أثر البديل في ترتيب الأصل، فيض الإجمالي، تأكيد نصي لمعلومة غير مؤكدة.

## حدود التحقق
لا فحص ثابت لأنواع TypeScript. لا معاينة متصفح أو RTL/جوال فعلية. لا مصادر أو أسعار أو شحن حقيقي ولا نجاح شراء. اختبار textContent من مراجعة الشفرة لا يثبت اختبار حقن في متصفح. الـ46 اختبارًا ليست إعلان اجتياز كل T01–T12 أو CMP أو BAT. قواعد الترجيح 60% تكلفة و25% موعد و10% إرجاع و5% هوية بائع قواعد أولية معلنة، وليست نسبة جودة.

النموذج يقارن هوية النسخة والشروط الإلزامية أولًا، ويستبعد النافد والمخالف، ويميز المجهول والمتعارض والقديم. السعر الناقص لا يفوز كأرخص إجمالًا؛ البدائل تحتاج إذنًا وتأتي بعد المطلوب. النتيجة الاصطناعية لا تحقق هدف الشراء. تحويل العملة والتكامل الحقيقي مؤجلان.
